How It Works

Three steps. That's it.

Create your project

Run one command and follow the interactive prompts.

npx easybeezy create

Pick your plugins

Select from 36+ plugins during setup — or add them later.

easybeezy add axios

Start building

Your project runs immediately. Zero manual configuration.

npm run dev
