How It Works

1. Create your project

Run one command and follow the interactive prompts.

npx easybeezy create

2. Pick your plugins

Select Axios, Zustand, Redux, or Tailwind during setup — or add them later.

easybeezy add axios

3. Start building

Your project runs immediately. No configuration needed.

npm run dev
